Starlight OS Vega → Fedora conversion
======================================

Applied visual profile
----------------------
* Starlight wallpaper registration for the desktop and a separate 4K Starlight
  asset for the GDM login screen, amber/dark dconf defaults, floating dark
  Dash-to-Dock settings, Blur My Shell,
  the User Themes extension, the local Starlight Clock Right extension, and
  the optional Starlight Brighter extension for dim notebook displays.
  The Starlight GNOME Shell layer styles the top bar, clock and quick settings;
  the GTK 3/4 layer styles applications that honor GTK themes.
* Dash to Dock, AppIndicator, Caffeine, Blur My Shell, and Kiwi Menu (version
  1.6.4, SHA-256 e097c80d0bec5e832059e26ee33b0ad353c0ec830bffdcb84295e30143106447)
  are installed with this package. Tiling Assistant is not in
  the enabled Fedora repositories, so it is not fetched implicitly.
* LinuxToys 6.4.8 is bundled from the repository's tracked upstream source
  archive. Its own scripts detect and support Fedora/DNF; it is not installed
  from the Debian `.deb`.
* Starlight-Colloid-Yellow-Dark icon theme is built from the repository's
  tracked source archive and installed under /usr/share/icons.
* A dedicated Starlight Plymouth theme replaces Fedora's watermark during
  boot, reboot and shutdown while the package is installed.

Fedora application mappings (applied only when the package is available)
-----------------------------------------------------------------------
Firefox ESR → firefox; GNOME extension packages → Fedora's corresponding
gnome-shell-extension-* packages; PipeWire, GNOME Software, Flatseal, fwupd,
media, device integration, development, virtualization and gaming packages are
mapped in starlight-fedora-apply. The graphical Starlight profile launcher runs
that helper, displays its progress and changes into a restore/removal entry when
the operation succeeds. ZapZap, Bazaar and Telegram remain system Flatpaks from
Flathub.
The Fedora profile installs programming fonts without selecting a new global
monospace or terminal font.

Not applied: Debian-only or unavailable upstream components
-----------------------------------------------------------
* live-build, debootstrap, live-boot/live-config, Calamares configuration,
  Debian APT sources, apt/nala/gdebi/synaptic/debsums/apt-listchanges,
  dpkg i386 handling, Debian firmware and microcode package names.
* Debian packages bundled by the ISO: WPS Office .deb, LinuxToys .deb, Linux
  Mint WebApp Manager .deb, Element's Debian APT repository, and Debian's
  desktop-base wallpaper alternatives.
* Debian-specific Firefox policy path (/usr/share/firefox-esr), GRUB/Syslinux
  ISO branding, and live-session/autologin components. The Fedora profile uses
  its own reversible Plymouth and GDM integration instead.
* WPS Office 12 is downloaded from the vendor's official Linux CDN as a native
  x86_64 RPM and verified against a pinned SHA-256 before installation. Starlight
  launchers select its bundled English interface without changing the desktop
  locale. It replaces LibreOffice; the latter is recorded and restored by
  rollback.
* Incus, its client/tools, lxcfs, dnsmasq, Btrfs, and LVM are direct RPM
  dependencies. Steam is applied when its repository is enabled (normally RPM
  Fusion); because it is already installed it is not recorded or removed by
  rollback. GOverlay, vkBasalt, ZFS, and proprietary codecs still depend on
  the enabled Fedora repositories; the apply helper reports unavailable
  packages instead of enabling third-party repositories or silently ignoring a
  failed transaction.

Rollback
--------
sudo starlight-fedora-rollback
  Removes only packages and Flatpaks recorded as newly installed by the apply
  helper, then reinstalls the applications it replaced (including LibreOffice
  components) and restores the previous user avatar when it is still unchanged.

sudo starlight-fedora-rollback --purge-assets
  Also removes the RPM, which removes its wallpaper, icon theme, extension and
  system dconf defaults.

starlight-fedora-reset-gnome
  Run as each desktop user after rollback to reset that user's dconf overrides.
